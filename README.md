# Bogdan's Recovery Ltd website

Next.js website ready for Vercel.

## Upload to Vercel
1. Extract this ZIP.
2. Upload/import the folder to GitHub or Vercel.
3. Build command: `npm run build`
4. Output: Next.js default / standalone.
5. Connect domain: `bogdanrecovery.co.uk`.

Main files:
- `app/page.tsx`
- `app/globals.css`
- `public/recovery-hero.svg`
